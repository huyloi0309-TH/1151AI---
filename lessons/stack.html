Stack

1. Concept explanation

A stack is a list where you can only add or remove items at one end, called the top. Think of a pile of plates: you put a new plate on top, and you take the top plate first.

This rule is called LIFO: Last In, First Out. The newest item always leaves first. Stacks solve the problem of remembering things in reverse order.

2. Visual explanation

A was pushed first, so it is at the bottom. C was pushed last, so it is on top and will leave first.

5. Real-world applications

  • Undo: an editor pushes each action, and Undo pops the latest one.
  • Browser back button: visited pages are pushed, and Back pops the current page.
  • Function calls: programs use a call stack to return to the right place.
