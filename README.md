# Data Structures Learning Hub

A beginner-friendly website that teaches data structures with visual explanations, step-by-step demos, interactive practice, and quizzes.

- Live site: add your GitHub Pages link here
- Rules for AI agents: see [AGENTS.md](AGENTS.md)

## Run locally

ES modules need a server. In this folder run:

    python -m http.server 8000

Then open http://localhost:8000

## Deploy

GitHub repository → Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Add a lesson

Ask your AI agent: "Add the Queue lesson." It follows section 9 of AGENTS.md. The Stack lesson is the reference.
